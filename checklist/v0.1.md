# MediTrack SRS Validation Checklist (v0.1)

| ID | Item | Answer | Evidence | Where question came from |
| :--- | :--- | :--- | :--- | :--- |
| **CL-001** | Does each requirement contain only one "shall" or "may" statement? | | | Rule: Clear |
| **CL-002** | Is every requirement free of undefined vague words (e.g. "quickly", "user-friendly", "securely", "normal", "policy")? | | | Rule: Clear |
| **CL-003** | Does every speed or time requirement state a number and a unit? | | | Rule: Testable |
| **CL-004** | Could a pass/fail test be written for every requirement? | | | Rule: Testable |
| **CL-005** | Are all appointment duration rules free of direct contradictions? | | | Rule: Free of contradictions |
| **CL-006** | Does the document define the exact system behavior when two users select the same time slot simultaneously? | | | Risk: Double booking concurrency |
| **CL-007** | Does the document specify the exact lead time (in hours or days) before an appointment when reminders are sent? | | | Risk: Missed appointments / no-shows |
| **CL-008** | Does the document state the communication channel (e.g., SMS, phone call, email) used for appointment reminders? | | | Risk: Elderly patients missing digital alerts |
| **CL-009** | Does the document specify a minimum cutoff window before an appointment after which online cancellation is restricted? | | | Risk: Last-minute cancellations leaving empty slots |
| **CL-010** | Does the document define how emergency walk-in patients are prioritized when all slots are already booked? | | | Risk: Emergency walk-ins delayed |
| **CL-011** | Does the document specify the peak concurrent user load expected during busy periods such as Monday mornings? | | | Risk: Monday morning system slowdown/crash |
| **CL-012** | Does the document state whether patients can reschedule an existing appointment without cancelling first? | | | User: Patient |
| **CL-013** | Does the document allow doctors to block off unavailable time slots (e.g., breaks, leave, surgeries) in their schedule? | | | User: Doctor |
| **CL-014** | Does the document specify how receptionists resolve or override scheduling conflicts for phone bookings? | | | User: Receptionist |
| **CL-015** | Does the document define the exact numerical rules for handling overdue payments? | | | User: Clinic administrator |
| **CL-016** | Does the document specify which user roles are permitted to view patient medical records? | | | User: Data protection officer |
| **CL-017** | Does the document specify the encryption standard required for storing patient records? | | | User: Data protection officer |
| **CL-018** | Does the document define the exact days and clock hours that constitute normal working hours? | | | Rule: Complete |
